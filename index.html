01 / IMAGE CLASSIFICATION

ClassifyAnythingPy

使用人工生成的图像微调 Vision Transformer，无需真实训练数据即可构建自定义图像分类器。训练、评估、可视化和推理集中在一个轻量项目中。

Python 3.11 PyTorch Transformers ViT

准备合成数据

按类别整理到 artificial_data 的子目录。

微调 ViT 模型

在 config.yaml 中管理模型与训练参数。

部署图像推理

加载本地或 Hugging Face Hub 模型进行预测。

从数据到预测

集中配置

数据路径、批量大小、学习率、训练轮次和模型输出目录均由 YAML 管理。

训练可观测

支持准确率评估、TensorBoard 日志，以及损失和准确率曲线可视化。

灵活推理

支持单张图片预测与目录批量推理，兼容 PNG、JPG、JPEG 和 WebP。

快速开始

unzip ClassifyAnythingPy/classify-anything-main.zip
cd classify-anything-main
poetry install
poetry run python src/classification_utils/fine_tuning_vit.py
