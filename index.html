让视觉智能
触手可及。

面向边缘智能视觉任务的 Python 项目合集。从图像分类、自然语言目标定位到图像与视频分割，用清晰的工具链构建自己的视觉应用。

图像分类 目标定位 图像与视频分割
01 / IMAGE CLASSIFICATION

ClassifyAnythingPy

使用人工生成的图像微调 Vision Transformer，无需真实训练数据即可构建自定义图像分类器。训练、评估、可视化和推理集中在一个轻量项目中。

Python 3.11 PyTorch Transformers ViT
下载项目源码 →

准备合成数据

按类别整理到 artificial_data 的子目录。

微调 ViT 模型

在 config.yaml 中管理模型与训练参数。

部署图像推理

加载本地或 Hugging Face Hub 模型进行预测。

02 / VISUAL GROUNDING

LocateAnythingPy

基于 NVIDIA Eagle 的通用视觉语言定位模型。通过并行边界框解码，在一次前向传播中预测完整坐标，在复杂场景中定位目标、文字与界面元素。

Eagle LocateAnything-3B Parallel Box Decoding
下载 Eagle 与 LocateAnything 源码 →

自然语言目标定位

支持指代表达、多目标检测和密集场景。

OCR 与 GUI 定位

输出文字区域、界面元素边界框或目标点。

快速而稳定

并行推理与自回归回退相结合，支持批量处理。

03 / IMAGE & VIDEO SEGMENTATION

SegmentAnythingPy

基于 Meta SAM 3 的可提示分割模型。通过开放词汇文本或视觉示例找到并分割全部目标实例，在图像和视频中完成检测、分割与跟踪。

SAM 3 Concept Segmentation Video Tracking
下载 SAM 3 源码 →

多种提示方式

使用文本、点、边界框、掩码或图像示例。

开放词汇分割

分割短语所描述概念的全部目标实例。

图像与视频统一处理

支持视频目标跟踪和交互式结果修正。

ClassifyAnythingPy：从数据到预测

集中配置

数据路径、批量大小、学习率、训练轮次和模型输出目录均由 YAML 管理。

训练可观测

支持准确率评估、TensorBoard 日志，以及损失和准确率曲线可视化。

灵活推理

支持单张图片预测与目录批量推理，兼容 PNG、JPG、JPEG 和 WebP。

快速开始

unzip ClassifyAnythingPy/classify-anything-main.zip
cd classify-anything-main
poetry install
poetry run python src/classification_utils/fine_tuning_vit.py
